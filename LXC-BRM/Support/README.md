# Support

This folder contains the non-app support material for the native macOS build manager.

- `shared`
- `frameworks`
- `build-release`
- `worklog`
- `context`

## Release Output

- `build-release/version` is the folder where the final versioned release package is staged.
- The final `.dmg` should land in that folder at the end of the release flow.

## Tracking Model

- All active todo tracking lives in `worklog/todo-2026-08-16.md`.
- The other support folders keep README files and reference material only.

## Index Files

- `context/requirements.md` — full functional requirements, in-repo copy of the source PDF
- `worklog/todo-2026-08-16.md` — phased build plan and tracking against those requirements
- `context/rules-context.md`
- `context/architecture.md`
- `context/decisions/decision-2026-08-16.md`

# LXC-BRM macOS App

This folder contains the native macOS workspace for Build Manager.

## Open In Xcode

Open `LXC-BRM.xcworkspace` or `LXC-BRM.xcodeproj` from this folder.

## Structure

- `App/` for the SwiftUI app shell
- `BRM/` for the macOS workspace folders and dated todo notes
- `LXC-BRM.xcodeproj` for the native Xcode project
- `LXC-BRM.xcworkspace` for the Xcode workspace wrapper

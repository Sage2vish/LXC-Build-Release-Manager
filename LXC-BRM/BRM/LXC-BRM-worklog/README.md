# LXC-BRM-worklog

This folder is the single home for active todo tracking, daily progress notes, and release follow-up.

## Purpose

- Keep all active todo items in one place.
- Record what was done, what is still open, and what needs a follow-up.
- Link out to the context and build-release folders instead of duplicating todo files there.

## Active Files

- `todo-2026-08-16.md` for the master running checklist
- `worklog-2026-08-16.md` for the written summary of completed work

## How To Use This Folder

- Add new tasks and subtasks to `todo-2026-08-16.md`.
- Update the tracking table when work changes status.
- Use `worklog-2026-08-16.md` for the narrative recap after the todo items are updated.
- Keep all other BRM folders free of active todo files.
